Capítulo 1 · Fundamentación y Objetivos IAgroCorr

Fundamentación y Objetivos

¿Por qué en Corrientes?

Producción y Humedales en Equilibrio

Corrientes combina cadenas intensivas (arroz, forestal, tabaco, citrus) junto a los Esteros del Iberá (Sitio Ramsar) y los ríos Paraná, Uruguay, Corriente y Santa Lucía.

Impacto Regional (Banco Mundial, 2024): Reducir la brecha tecnológica en explotaciones medianas/familiares y certificar uso racional de insumos.
Relevancia Informática: Arquitectura híbrida Cloud/Local para integrar vectores OGC, series satelitales y modelos GeoIA.
Objetivo General (Anexo II)

Desarrollar una plataforma de Inteligencia Territorial que integre datos satelitales, cartografía oficial y aprendizaje automático para optimizar decisiones estratégicas, diversificación productiva y gestión de riesgos ambientales en Corrientes.

01

Data Warehouse Espacial y Plataforma Web OE2 · OE3 · OE6

Integrar capas de IDERA, IDECorr, INTA y GEE en PostGIS bajo una app web contenedorizada, portable y adaptable a escritorio y móvil.

02

Detección Temprana en Formato Semáforo OE1 · OE4

Detectar anomalías vegetativas (NDVI/NDWI) y riesgos fitosanitarios traduciendo métricas complejas a alertas simples (Verde, Amarillo, Rojo).

03

Motor de Gemelos Climáticos Globales OE5

Identificar zonas productivas mundiales análogas mediante clustering edafoclimático para recomendar alternativas de diversificación.

Arquitectura, Stack y Pipeline ETL

1. Extract & Cloud GIS

GCP + Earth Engine & OGC

Google Cloud Project + API GEE filtran nubes y reducen píxeles Sentinel-2 por polígono en la nube (JSON liviano, sin bajar GeoTIFFs). Cartografía IDECorr/IDERA y WMS INTA en vivo.

GEE API GCP IAM WMS INTA
2. Transform & DW

GeoDjango + PostGIS 3.4

Python 3.12/3.13 y Django 6 con GDAL/GEOS. Armoniza geometrías en SRID 4326, proyecta a EPSG:3857 para distancias/áreas exactas y carga de forma idempotente en PostgreSQL 16.

GeoDjango PostGIS GiST GDAL 3.13
3. Laboratorio GeoIA

Google Colab + Scikit-learn

Exploración EDA, escalado y entrenamiento CRISP-DM en notebooks de Google Colab con Pandas y Scikit-learn, exportando modelos serializados livianos (.joblib) al backend.

Google Colab Scikit-learn Pandas
4. Frontend & DevOps

Leaflet, Docker e IA Agéntica

Visor Leaflet + Geoman y Bootstrap 5 (Claro/Oscuro). Entorno unificado en Docker + VS Code Dev Containers, proxy Cloudflare, Jira/Zotero y desarrollo guiado por specs con Antigravity y Claude Code.

Docker Leaflet Antigravity · Claude Code

Conclusiones y Futuros Trabajos

Conclusiones Alcanzadas

De Datos Dispersos a Decisiones Explicables

  • La integración de PostGIS + WMS OGC + Semáforos auditables resuelve la problemática relevada con el INTA sin caer en modelos opacos de «caja negra».
  • Incorporar buffers legales de los Esteros del Iberá, cursos hídricos y bandas SENASA en la base espacial armoniza productividad y preservación ambiental.
  • La validación temprana con referentes regionales orientó el diseño hacia privacidad estricta por productor, contenedores portables y baja fricción visual.
